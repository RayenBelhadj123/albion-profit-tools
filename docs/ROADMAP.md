# Roadmap

## Phase 1: Foundation

- Environment validation
- Prisma schema
- Health endpoint
- Test runner
- Calculation engine

## Phase 2: Market Data

- Albion Online Data client
- Zod response validation
- Price cache
- Server and city support
- Stale data handling

## Phase 3: Private Data

- Manual private observations
- Quantity tracking
- Private override rules
- Effective price resolver

## Phase 4: Scanner

- Origin and destination selection
- Filters
- Sorting by profit, ROI, profit per kilogram, profit per minute, and quantity
- Opportunity explanations

## Phase 5: Planner

- Mixed-item transport load
- Capital and weight constraints
- Quantity constraints
- Save plans

## Phase 6: Trip History

- Record actual purchases and sales
- Compare expected and actual profit
- Accuracy reports

## Later

- CSV import
- historical charts
- route risk scoring
- Black Market support
- notifications
- advanced optimizer
